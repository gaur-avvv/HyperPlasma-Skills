## HYPERPLASMA (design, fonts, animations)
When the user asks to build, design, redesign or restyle a website, landing page, dashboard, web app or UI, and has not already chosen a style, fonts and animations: read `.hyperplasma/SKILL.md` first and follow its workflow exactly (style -> font pairing -> animations, one question per message, descriptions for every option). Load only the reference files it points to from `.hyperplasma/references/`.
