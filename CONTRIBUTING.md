# Contributing

1. Add entries as `- **ID. Name** [ENGINE] - one-line description.` (motion) or `- **ID. Name** - description.` (styles). Fonts use `- **Heading + Body** - feel.`
2. Use the next free ID, or map a repeat in the duplicate map instead of adding it twice.
3. Mark non-Google fonts with a dagger, paid/system fonts with a dollar sign, and unverified names with a question mark.
4. Run `python3 scripts/validate.py` before opening a PR; it must print `OK`.
5. Keep `SKILL.md` under 500 lines; put detail in `references/`.
