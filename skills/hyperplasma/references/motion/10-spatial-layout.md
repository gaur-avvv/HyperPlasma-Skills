# Spatial Layout Engines and Navigation Motion

Best for: tools, maps, canvases, creative sites with non-standard navigation.

- **91. Infinite Canvas Pan** [FM] - drag the plane on any axis with inertia.
- **92. 3D Stacking Deck Carousel** [FM/R3F] - cards in a circular depth index; target comes forward.
- **93. Radial Dial Unfold** [FM] - options deploy in a full circle around a touch point.
- **94. Parallax Route Slide** [FM/GSAP] - background layers move at half the foreground speed during transitions.
- **95. Node Pipeline Spring Rebound** [FM] - connected blocks reposition with spring physics.
- **96. Split-Pane Matrix Resize** [FM/CSS] - side-by-side panels resize smoothly and scale contents.
- **97. Z-Axis Multi-Layer Drift** [CSS/GSAP] - overlapping image sheets drift at varied speeds on pan.
- **98. Command Palette Unroll** [FM] - search cells unfold vertically like a paper scroll (multi-tier variant: ID 127).
- **99. Dynamic Grid Snap** [FM] - floating dashboard panels pull into alignment when dropped.
- **100. Perspective Tunnel Open** [FM/GSAP] - app frame scales up from center while rotating into alignment.
