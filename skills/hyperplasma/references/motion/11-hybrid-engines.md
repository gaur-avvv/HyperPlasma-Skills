# Hybrid and Mixed-Engine Techniques [HYB]

Best for: demanding projects that combine React state, scroll timelines, canvas and native CSS. Use only when a single engine cannot do the job.

- **301. Framer-GSAP Dual-Engine Portal** - Framer Motion handles UI layout morphs; GSAP ScrollTrigger handles full-bleed scroll scrub.
- **302. CSS Web-Timeline React Hydrator** - read native CSS `view()` progress inside React and expose it as state tokens.
- **303. WebGL Canvas Text Mask Intercept** - Next.js wrapper renders page titles as liquid fragment-shader meshes in a Canvas overlay.
- **304. WAAPI Variable Injector** - Web Animations API bound to CSS variables in a React grid for thousands of micro-elements.
- **305. Three.js DOM-to-3D Bridge** - map React DOM buttons onto coordinates in a floating 3D model.
- **306. Scroll-Driven SVG Morph Context** - GSAP MorphSVG warps inline SVG while Framer Motion scales the card layout.
- **307. Hardware-Accelerated Shadow Proximity** - vanilla pointer telemetry drives native CSS 3D layer translation to avoid layout lag.
- **308. Next.js Route Sheet Shifter** - App Router hooks plus GSAP timelines slide the old page up while a new canvas drops in.
- **309. Lottie Memory Allocator** - cache Lottie vector paths in memory buffers during ScrollTrigger sequences.
- **310. Particle Network CSS Variable Feed** - HTML input values feed an HTML5 Canvas physics loop to change attraction fields live.
- **311. Responsive Flex-Grow Injector** - React layout shifts trigger stiff-spring flex-grow rebalancing.
- **312. Clip-Path Canvas Fluid Wave Sweep** - CSS clip-path transitions combined with Canvas noise.
- **313. Marquee Text-Splitting Intercept** - GSAP SplitText over an infinite CSS marquee stream.
- **314. 3D Tilt Canvas Blend Layer** - CSS 3D tilt plus a Canvas shader lens-flare overlay.
- **315. Anisotropic Drag Physics Boundary** - Framer Motion drag constraints plus GSAP inertia for spring-loaded panning on large boards.
- **317. Flow Node Line Connector** - lightweight SVG lines connect React cards and re-route as modules scale.
- **320. Raycaster Mouse Projection Grid** - project 2D UI coordinates onto a 3D perspective plane and track the cursor across floating cells.
- **426. WAAPI Multi-Element Keyframe Hydrator** - drive thousands of dashboard nodes via native browser animations, bypassing layout-pipeline blocks.
