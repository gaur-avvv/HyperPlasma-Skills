# Micro-Interactions, Hover States and Touch Gestures

Best for: buttons, cards, menus, mobile. Keep hover effects off touch devices; use transform and opacity only.

- **41. Magnetic Button Pull** [FM/GSAP] - CTA is attracted to the pointer inside a ~40-50px zone.
- **42. Elastic Liquid Hover** [FM/CSS] - card corners warp like heavy gel.
- **43. Specular Light Sweep** [CSS] - bright gradient flash crosses a metallic surface on hover.
- **44. 3D Tilt Matrix** [FM/CSS] - card tilts on a 3D plane with highlights following the cursor.
- **45. Chromatic Aberration Shake** [CSS/GSAP] - text RGB channels split briefly on click.
- **46. Micro-Squish Press** [FM/CSS] - button compresses ~6-8% on press, rebounds past size on release.
- **47. Text Wave Ripple** [FM/GSAP] - letters jump in a rapid wave on menu hover.
- **48. Stripe Shift Fill** [CSS] - diagonal color wedge sweeps across the background.
- **49. Icon Rotation Burst** [FM/CSS] - icon rotates 180 degrees while small accent nodes burst outward.
- **50. Neon Glow Ignite** [CSS] - thin border lights up with neon shadow on focus.
- **101. Swipe-to-Dismiss Rubber Banding** [FM] - rising pull resistance near edges; snaps back if released early.
- **102. Elastic Edge Pull Refresh** [FM] - rubber-sheet pull-to-refresh with spinner and spring snap shut.
- **103. Velocity-Based Inertial Scroll** [FM/GSAP] - carousel keeps flick speed with exponential decay.
- **104. Pinch-to-Zoom Focus Anchor** [FM] - zoom from the midpoint between two fingers.
- **105. Drag-and-Drop Tilt Offset** [FM] - picked-up item tips ~5 degrees and follows with loose springs.
- **106. Tinder-Style Rotation Sweep** [FM] - card rotates on a curved radius with drag; flies off past threshold.
- **107. Tilt-Shift Ambient Shadow** [FM/CSS] - shadow blur and offset grow with elevation.
- **108. Long-Press Progress Warp** [FM/CSS] - glowing loop fills the button perimeter; fires only when complete.
- **109. Scratch-Card Pixel Reveal** [CNV] - erase a matte layer under the touch path to reveal content.
- **110. Magnetic Proximity Dock Snap** [FM] - floating modules snap to dock margins when near.
