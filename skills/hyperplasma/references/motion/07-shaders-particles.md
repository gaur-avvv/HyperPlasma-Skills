# Shaders, Particles, Liquid and Distortion [CNV]

Best for: hero sections, creative portfolios, art-forward brands. Heavy on GPU; cap particle counts, pause off-screen, provide a static fallback.

- **61. Molten Chrome Ripple** - oil-slick liquid metal reacts to the pointer.
- **62. Magnetic Particle Swarm** - thousands of points cluster around the cursor.
- **63. Ink-in-Water Bleed** - ink clouds billow and dissolve inside menu blocks.
- **64. Grid Web Displacement** - mesh grid stretches as elements drift past.
- **65. Torn Paper Shred** - UI box tears along a jagged edge on delete.
- **66. Smoke Trailing** - volumetric smoke follows the cursor on dark layouts.
- **67. Displacement Glitch Wave** - horizontal pixel-shift waves fake analog errors.
- **68. Canvas Bubble Pop** - glass orbs float up and shatter into micro-particles.
- **69. Magnetic Constellation Web** - nodes connect with thin lines when near each other.
- **70. Grain Static Flicker** - oscillating film-grain overlay for a physical feel.
- **111. Liquid Dissolve** - image melts into a ripple pool before reforming as the target.
- **112. Perlin Noise Dispersion** - solid text disperses into drifting dust driven by noise.
- **113. Ray-Traced Refraction Prism** - glass prism bar bends pixels across flat UI.
- **114. Sinusoidal Wave Ripple** - continuous water wave clears the current route.
- **115. RGB Channel Split Reveal** - red/green/blue bands overlap to form the final image.
- **116. Molten Chrome Inversion** - chrome displacement swallows an element inside out at the cursor.
- **117. Thermal Heat Map Expansion** - content bleeds open from cold indigo to electric magma by pointer speed.
- **118. Vector Page Shred** - dashboard panels split along a jagged generated boundary.
- **119. Volumetric Fog Wipe** - 3D gas particles sweep over the layout and clear components.
- **120. Xerox Photocopy Burn Fade** - scanner-lamp sweep with edge burns and toner static.
