Best for: dashboards, SaaS, e-commerce, any React app with state-driven UI.

- **2. Shared Element Transition** [FM] - card image flies from grid into full-screen detail view.
- **3. Layout Grid Reordering** [FM] - neighbors slide aside when items are sorted or deleted.
- **4. Accordion Staggered Expansion** [FM] - dropdown content opens with cubic-bezier height and staggered children.
- **5. Floating Action Menu Pop** [FM] - secondary buttons expand outward from one anchor.
- **6. Dynamic Tab Slider Indicator** [FM] - highlight pill glides behind tab labels.
- **7. Command Palette Summon** [FM] - keyboard-first field scales into screen center with a soft bounce.
- **8. Sidebar Sheet Drawer Flyout** [FM] - drawer slides in with spring shadow; main content may scale back.
- **9. Bento Cell Hover Inflation** [FM] - hovered bento cell grows while neighbors resize.
- **10. Staggered List Entrance** [FM] - rows enter bottom to top with index-based delay.
- **121. Search-Bar-to-Dashboard Expansion** [FM] - floating search capsule expands into a full metrics grid via shared layout ID.

- **123. Dynamic Cart Drawer Expansion** [FM] - cart panel slides open while the catalog compresses to avoid overlap.
