# Native CSS and Web Animations API [CSS]

Best for: performance-first sites, static sites, anywhere JS animation libraries are overkill. Browser support for `animation-timeline` varies; provide a fallback.

- **51. View-Timeline Reveal** - `animation-timeline: view()` ties opacity/transform to viewport entry.
- **52. Scroll-Driven Color Shift** - interpolate root variables (e.g. `--bg-color`) over scroll.
- **53. Infinite Linear Spin** - rotate vector badges with CSS keyframes, no JS.
- **54. Clip-Path Polygon Morph** - transition `clip-path` from square to star, triangle to hexagon.
- **55. Sticky Header Compress** - header shrinks and shifts opacity once scrolling starts (about 50-60px).
- **56. Backdrop-Blur Sweep** - glass filter sheet slides across sharp imagery.
- **57. Flex-Grow Shift** - hovered gallery cell grows via `flex-grow`.
- **58. Z-Index / Z-Translate Cascade** - elements lift toward the viewer via 3D translate.
- **59. Step Timing Run** - `steps()` for retro loading bars and sprite animation.
- **60. Variable Font Weight Scrub** - morph weight with scroll, hover, or velocity.
- **180. Scroll-Direction Header Toggle** - swap header tokens the moment scroll direction reverses.
- **261. CSS Masonry Hover Morph** - neighbors re-proportion smoothly in a grid on hover.
- **264. Directional Clip-Path Wipe** - cover layer wipes left to right via `mask-image`/`clip-path`.
- **265. Accessible Inversion** - `mix-blend-mode: difference` inverts colors inside cards.
- **266. Aspect-Ratio Scaling** - media containers re-proportion smoothly with `aspect-ratio`.
- **267. Infinite Pulse Radial Glow** - concentric circles expand continuously from a button.
- **268. Bouncing Loading Dots** - staggered bounce via `animation-delay`.
- **269. Text-Shadow Elevation Lift** - deeper ambient shadow on hover.
- **270. Pure CSS Tooltip Fade** - opacity transition on parent focus/hover.
- **271. Multi-Column Expand** - `column-count` adapts to viewport width.
- **272. Hue-Rotate Spectrum Shift** - continuous gradient color rotation via `hue-rotate`.
- **273. Grayscale Dissolve** - color to black-and-white with CSS filter transition.
- **274. Circular Clip-Path Zoom Reveal** - circle expands from image center on focus.
- **275. Smooth Anchor Scrolling** - `scroll-behavior: smooth` for in-page links.
