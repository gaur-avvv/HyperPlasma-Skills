# Tech, Sci-Fi, Spatial, and Geometric/Technical Styles

Best for: developer tools, security, GIS/data products, gaming, AI, engineering portfolios.

## Tech and sci-fi
- **66. Spatial UI (visionOS)** - hovering glass layers that react to room lighting; AR/VR-ready.
- **67. Holographic / Sci-Fi HUD** - floating aircraft dials, glowing teal readouts, radial graphs.
- **68. Skeuomorphic 3D (WebGI/Spline)** - scroll past fully rendered, spinning 3D product models.
- **69. Terminal UI** - command-line look: green courier text, running logs, code prompts.
- **70. Gaming HUD** - status trackers, weapon wheels, mini-map layouts.
- **72. Clay 3D Isometric** - dashboards as floating mini 3D towns seen from a fixed angle.
- **141. Tactical HUD** - fighter-jet visor: pitch indicators, distance telemetry, green reticles.
- **142. Terminal Dashboard** - monospaced code blocks, console streams, green/amber/red status chips.
- **200. Vector HUD Hybrid** - standard dashboard charts plus thin floating vector guides and reticles.
- **203. Photonic UI** - see morphisms file; energy-field glow instead of cards.
- **231. Deep Space HUD** - spacecraft panels: thin blue lines, orbit telemetry, glowing vector matrices.
- **232. Cyber-Gothic Grid** - neon data fields with cathedral arches, cross vectors, medieval fonts.
- **233. Alien Organic UI** - looks grown, not coded: chitinous shells, dark pulses, bio-ink displays.
- **234. Retro-Capsule Sci-Fi** - 1970s cinema: rounded beige plastic panels, orange CRT text, click buttons.
- **235. Exoskeleton UI** - frames wrap text zones like tactical armor or scaffolding.
- **236. Quantum Matrix** - micro-particle streams rearrange into structural dividers.
- **237. Simulated Holo-Glass** - flickering blue/amber panels with scanlines and tracking errors.
- **238. Tactical Mech Console** - military cockpit: hazard stripes, warning panels, radar frames.
- **239. Solar Sail Minimal** - ultra-thin glowing wireframe lines that catch light as you scroll.
- **240. AI Cortex Mesh** - moving nodes that flare with color when processing input.

## Geometric and technical drawing
- **151. Blueprint / Technical Drafting** - cyan/deep-blue paper, white grids, technical annotations.
- **152. Wireframe Isomorphism** - 3D objects as empty glowing grid frames showing polygons.
- **153. Golden Ratio Grid** - see layout file.
- **154. Isometric Grid (Pseudo-3D)** - uniform 30-degree grid to fake 3D without camera perspective.
- **155. Dot Matrix Grid** - micro-dot arrays replace solid grid lines.
- **156. Voronoi Tessellation** - organic distance-based cell polygons; shattered-glass mosaic.
- **157. Low-Poly Graphic** - minimal flat triangles, early retro-3D look.
- **158. High-Poly Technical** - dense mesh and intersecting vector lines showing detail.
- **159. Choreographed Motion UI** - layout lines and card edges expand on precise math timing curves.
- **160. Cross-Section UI** - panels sliced open to show internal layers, textbook style.
