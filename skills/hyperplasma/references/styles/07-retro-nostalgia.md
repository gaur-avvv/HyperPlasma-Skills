# Retro Software and Digital Nostalgia

Best for: fun side projects, personal sites, nostalgic brands, hackathon demos. Risk: usability and responsiveness suffer; keep it a skin, not a constraint.

- **26. Frutiger Aero** - mid-2000s gloss: glass textures, tropical greens/blues, water droplets, optimism.
- **27. Neo-Frutiger Aero** - modern revival: flat icons with glassy highlights and bubbly buttons.
- **87. Early Smart UI (PDA)** - color PDA touchscreens: chunky neon pill buttons, glossy plastic.
- **111. Frutiger Eco** - Aero plus wind turbines, recycling icons, grass under glass, solar themes.
- **112. Frutiger Aurora** - glossy 2000s textures with deep-space nebulae and glowing dark-blue waves.
- **113. Aqua UI (Mac OS X)** - translucent blue gel buttons, pinstripe backgrounds.
- **114. Luna UI (Windows XP)** - bright blue/olive/silver frames, rounded headers, red close button.
- **115. Aero Glass (Windows 7)** - heavy window blur, metallic reflections, transparent title bars.
- **116. Early iOS Skeuomorphism (iOS 6)** - legal-pad notes, linen texture, glossy app icons.
- **117. Net Art (Web 1.0)** - blue hyperlinks, grey table borders, blinking text, starfield tiles.
- **118. Glitch-Hop Aesthetic** - vector wireframes, VHS tracking lines, speaker cones, strobe layers.
- **211. System 7 (Vintage Mac)** - black-and-white grids, pixel icons, light grey windows.
- **212. Chicago Typography** - early Apple type, thick frames, retro status bars.
- **213. Amiga OS Classic** - bright primaries on workbench panels, blocky taskbars.
- **214. Commodore 64 Terminal** - dark blue screen, light-blue border, monospace, blinking block cursor.
- **215. Teletext / Ceefax** - low-res alphanumeric grids, blocky icons, solid primary backgrounds.
- **216. MS-DOS Shell** - blue canvas, double-line ASCII boxes, keyboard menus.
- **217. Windows 95 Classic** - bevels, grey plastic, dark-blue title bars, hard shadows.
- **218. Early Unix X11** - raw geometric grids, basic checkboxes, neon pixel highlights.
- **219. NeXTSTEP** - dark grey workspace, sharp bevels, multi-column shelf navigation.
- **220. BeOS Desktop** - yellow title tabs on light grey windows, sharp vector type.
